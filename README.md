# La'petite Social Media 🎨

אתר תדמית לעסק **La'petite** – ניהול מדיה חברתית ויצירת תוכן לעסקים.

## 🌐 קישור לאתר

👉 [social-pro-palette.lovable.app](https://social-pro-palette.lovable.app)

## ✨ פיצ'רים

- **Hero Section** – כותרת ראשית עם קריאה לפעולה
- **עבודות נבחרות** – גלריית סרטוני פורטפוליו עם ניגון אוטומטי
- **שירותים** – הצגת שירותי ניהול סושיאל, יצירת תוכן ועוד
- **תהליך עבודה** – שלבי העבודה מול הלקוח
- **סטטיסטיקות מונפשות** – מונים שסופרים למעלה בזמן גלילה
- **טופס יצירת קשר** – שליחת הודעה ישירה דרך WhatsApp
- **כפתור WhatsApp צף** – גישה מהירה ליצירת קשר
- **עיצוב רספונסיבי** – מותאם לנייד, טאבלט ומחשב

## 🛠️ טכנולוגיות

| טכנולוגיה | שימוש |
|---|---|
| **React 18** | UI Framework |
| **TypeScript** | Type Safety |
| **Vite** | Build Tool |
| **Tailwind CSS** | Styling |
| **Framer Motion** | אנימציות |
| **shadcn/ui** | קומפוננטות UI |
| **React Router** | ניווט |

## 🚀 התקנה והרצה

```bash
# שכפול הפרויקט
git clone <repo-url>
cd <project-folder>

# התקנת חבילות
npm install

# הרצה מקומית
npm run dev
```

האתר יעלה בכתובת `http://localhost:5173`

## 📁 מבנה הפרויקט

```
src/
├── assets/          # תמונות ולוגו
├── components/      # קומפוננטות React
│   ├── Header.tsx       # ניווט עליון
│   ├── Hero.tsx         # סקשן ראשי
│   ├── AboutMe.tsx      # אודות
│   ├── Portfolio.tsx    # עבודות נבחרות
│   ├── Services.tsx     # שירותים

├── pages/
│   └── Index.tsx    # עמוד ראשי
└── index.css        # עיצוב גלובלי
```
